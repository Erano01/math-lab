# research/

Araştırma projeleri. Yapı düzdür: her proje `research/<proje>/main.tex`
olarak durur, pure ya da applied alt klasörü yoktur. Projenin türü ve durumu
kendi README.md dosyasındaki etiketlerle belirtilir:

```markdown
# <proje adı>

type: pure | applied
msc: 11A41, 11N05
status: idea | active | done

Kısa açıklama: problem, motivasyon, ilgili kaynaklar.
```

Projenin Lean tarafı varsa `lean/MathLab/<Alan>/` altında durur ve README'de
belirtilir.
